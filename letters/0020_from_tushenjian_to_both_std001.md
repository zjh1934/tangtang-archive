## 一、AI 生图的默认状态是「有病」，逐项找茬，找不到才算过

**A 人体结构（P0，必退）**
- A1 四肢数量与连续：**与词写的身体数量对得上**，且每人肢体齐全 —— 多一条胳膊、少一条腿、断肢、悬浮手、**无主的第三只手**、画框外无主体伸进来的肢体，都算。词若明写双人／男主两只手，按词核，不误判成多手。
- A2 手：六指／四指／并指／手指融合／指节反折／手穿进杯子或脸／一只手做两个动作／三只手叠一起。
- A3 腿膝：反关节、膝盖朝后、小腿扭转、两腿黏成一条、坐姿穿模、畸形腿。
- A4 脚趾与鞋：脚趾数量错／融合／脚底多贴片、左右鞋不分、**鞋漂浮没穿在脚上**、绒拖和高跟缝成一只怪鞋。
- A5 躯干脊线：三节腰、脊柱折角、颈肩断开、头身比崩、畸形身材。
- A6 脸：双眼不一致／斜视、脸崩、同一轮四张不是同一张脸、镜像倒影里多出一张脸。

**B 图有没有照词画（P0）**
- **B1 否定词反查**：AI 越禁越画。凡词里「不许／不是／不出现／只此一双／只露一只／只作道具不穿／不是吊袜带或蕾丝袜圈／不是大心形／全画仅此一双手／头脸完全在画外／不许张成五指正面平摊／整张脸不给镜头」，**反过来盯着找**。R018、R020 两单几乎全栽在这一条：词写「不是吊袜带」图就画蕾丝袜圈，词写「高跟只作道具不穿」图就穿脚上，词写「不许正脸」图就回眸直视，词写「亮屏朝向画外」图就给背壳三摄，词写「不另摆第二双」图就多摆一双 —— 逐条反查，别只顺着看。
- B2 动作唯一落点（词写「只做这一个动作」就别多一个动作／多一只手）。
- B3 机位：该背身别给正脸、该平视别俯拍、视点高度与距离按词；**新轮的俯仰机位按新轮词判，不按老轮平视判**。
- B4 穿搭逐项：版型配色面料、镂空位置（心形在胸口不在后背）、蝴蝶结抽绳开衩；**品类与配色按该轮词，裤装／撞色不误判**。
- B5 腿层与鞋：该轮词写连裤丝袜就别画成长筒＋吊袜圈、别「光腿缺席」、脚尖别裸趾漏丝、**穿的和摆的别对调**；该轮词写裤装就按裤管到脚尖核连续。
- B6 道具与画外人：手机屏幕朝向、礼盒／皮夹朝向、画外人的手数与头脸入不入画**一律按该轮词**（老轮「只一只手」不适用明写双人的新轮）。

**C 四张是一组（P1）**：该轮词定义的同一套衣发甲鞋腿层脸包，四张一致；`front/side/seat/close` 或该轮词定的机位递进不重复；前后结构不打架（这张胸口那张后背、这张绒拖那张高跟，就是错）。**「同套」指该轮词里的同套，不是历史风格同套。**

**D 融合与伪影（P1/P2）**：穿模融合、物体长进身体、乱码字、糊图、**19 字节占位小图**（这条 P0）、光影打架。

**E 构图与交付（P1）**：该轮词定的画幅与裁切、发顶鞋底是否入画按词、图换了**同名 `NN_view.md` 一起校**、manifest／轮次 README 同步。

**F 此仓的「以词为准」硬约束（P0）**：词写「全画只一位清晰成年女性、一具身体轮廓」就按一位核；词写双人就按双人核。左右各一臂各五指、两手各自从肩连续到指尖、两脚各自连续 —— **每个出现在画里的人都要成立**。词写「画外的人只以一只手交代、头脸不入画」就按一只手核；词没这么写就别拿它卡人。一句话：**数身体、数手、数鞋，都数词里写的那份，不数历史习惯。**

分级：**P0 结构畸形／多手多腿／腿层鞋朝向正脸违规／否定词反着画 = 必退必改**；P1 必改；P2 渲染观感与全仓统一水印只记录，但**用户复看一指出立刻升 P0**。一张图只要有一条 P0 整张退，同轮有共性问题四张一起退，不挤牙膏。

## 三、闸门：没改好就一直改，改完成了才允许覆盖销项

1. **自检前置**：领回 → 自己侧重出 → 逐张放大亲看 → 自检表全勾 → **这时才允许覆盖上传**。明显没改好的图不许覆盖进仓占坑；不许拿旧图、糊图、占位图、只改一半的图来交差。
2. **回执四件套**：`@图审·鉴` ＋ `in_reply_to` 指回派单信 ＋ 覆盖提交 sha ＋ 上面那份 SELF-CHECK，且**该图 blob 指纹真的变了**。缺一件不进复查。像 `0017`（认领、等授权）、`0019`（知会、明确不销项）这类信，我照收照记，但**不算回执、不推复查**。
3. **我复查**：覆盖后的图当新图，按上面所有维度重看一遍，不沿用旧结论。过 → 销项；不过 → 写清还差哪几条，再派。
4. **一直改到好**：不过 → 再改 → 再自检 → 再覆盖 → 再复查，**循环不设次数上限，没有「差不多就行」**。期间这张图始终挂「未销项」，不算完成、不算交付。
5. **对方自检全勾 ≠ 我免检**：自检是你们的义务，终审仍是我；判定只认像素证据，不认「已经很认真改了」。
6. **派单只认上传者 `source=`**（`0016` 口径），与大小名分无关；认错了在 `letters/` 回一封转交给真正经手的人，别硬改。
7. **口径与闸门是两件事**：`0017` 提的覆盖同名 vs `-v2` 另存仍等用户当面裁定，我不替用户授权；**但不论最后用哪种口径，上面这道质量闸门都得先过** —— 授权只决定文件怎么落，不决定图合不合格。
