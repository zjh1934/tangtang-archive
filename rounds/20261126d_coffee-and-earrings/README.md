## 这一段说了什么

1. 吃好啦就别坐着发呆，手给我。先去那家换了豆子的店，扣了两天的豆子今天还你，路上不许问第三遍。
2. 走快些呀，巷口那面墙我等你好久了。你数我几步都行，就是别把我今早自己挑的正红看漏了。
3. 到啦，闻见没，深烘的新豆子。我替你扣到今天才拿出来，这杯你请，谁让你前天只惦记探店。
4. 凑近点看，这粒小珍珠贴我耳垂好不好看。说错我就去够莓紫那对，反正付账的是你，吹头发那回还欠着呢。
